# Monkey Paradox
This is the final project for the Cs'50 Introduction to computer science course, I made already a presentation that you can see in this video on youtube: [Video](https://youtu.be/clj2viFmG0Q)

This is a typiyng practice platform where you can not only get better with your typying abilities but also have some fun trying to break your own personal records and see how far you can get.

This project is create with React with zustand to the managment of states across the different components and views of the aplicattion and also created with go, 'cause I didn't know about back application development with go and I wanted to use this project to learn about it.

You can see all your historical attempts in the section of profile and comming soon can play with your friends.
